# Перенос из архивного Swift-клиента → Flutter (чек-лист схлопывания)

Единая база теперь одна — эта (Flutter). Swift-репо `~/bitaps-vpn-app` заморожен (см. его README).
Ниже — что в нём было ценного и чего пока нет здесь. Переносим по мере надобности; отмечать галочкой
по факту переноса. Ничего из Swift **не удаляем**, пока соответствующая фича не перенесена сюда.

## Уже есть в Flutter (перенесено / сделано заново)
- [x] Экран коннекта: кнопка-питание, статусы, таймер, ↓/↑ скорости, IP, «Авто — быстрейший сервер».
- [x] Серверы: РФ-ноды + зарубежные, пинг-тест, сортировка/авто-выбор по пингу.
- [x] Подписка/кабинет: план, устройства, продление, вход через Telegram-пейринг.
- [x] Настройки: 5 акцент-тем, стили кнопки, PIN-замок, авто-подключение, свой конфиг (BYO), спид-тест, leak-check.
- [x] **Тёмная + светлая + системная тема** (переключатель в Настройках).
- [x] Режимы маршрутизации (Авто/Стрим/Игры/Прив.) — подбор сервера по режиму.
- [x] Тумблеры «Обрыв соединения» и «Лимит трафика» — рабочие (не заглушки).
- [x] Генератор sing-box конфига на 5 протоколов (`singbox_config.dart`).

## Нативный туннель (главный блокер боевого VPN)
- [ ] Apple: перенести `PacketTunnel/PacketTunnelProvider.swift` + `Libbox.xcframework` в macOS/iOS-раннер
      (готовый код в Swift-репо — переиспользовать целиком). Подробно: `TUNNEL.md`.
- [ ] Android: `VpnService` + gomobile-сборка `libbox.aar`.
- [ ] Windows/Linux: бинарь `sing-box` + нативный плагин-обёртка.

## Фичи из Swift, которых здесь ещё НЕТ (кандидаты на перенос)
- [ ] **Live Activity + Dynamic Island + виджет** (iOS) — статус подключения на локскрине/домашнем.
- [ ] **MenuBar-пункт** (macOS) — быстрый коннект/смена локации из строки меню.
- [ ] **Статистика**: суммарный трафик + история подключений (сейчас в Flutter только счётчик сессий).
- [ ] **Свой конфиг**: QR-сканер (iOS) для импорта ключа — в Flutter только вставка из буфера.
- [ ] DNS-пресеты, split-tunnel — были в Swift-настройках, здесь пока нет.
- [ ] EN-локализация UI (в Swift был RU/EN; здесь интерфейс в основном RU).

## Порядок
1. Сначала — нативный туннель хотя бы на одной платформе (это отделяет продукт от демо).
2. Потом — фичи по спросу (Live Activity/виджет и статистика дают наибольшую ценность пользователю).
3. Как перенесли всё нужное — Swift-репо можно архивировать окончательно (tag + read-only).

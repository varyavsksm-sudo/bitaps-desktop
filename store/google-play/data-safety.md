# Google Play — форма Data Safety (ответы по разделам)

Контекст: приложение не содержит рекламы, аналитических SDK и трекеров. Продажи идут
через Telegram-бота/сайт (вне приложения), поэтому платёжных данных приложение не видит.

## Собираемые данные

**Личная информация → Идентификатор пользователя (User ID)**
- Что: Telegram ID аккаунта (для проверки лицензии) и UUID подписки.
- Зачем: app functionality (вход в аккаунт, показ подписки, выдача конфигурации).
- Обязательно/опционально: обязательно для работы приложения.
- Передаём ли третьим сторонам: НЕТ.
- Обрабатывается временно (ephemeral): нет (хранится на устройстве и в аккаунте).

**Идентификаторы устройства (Device or other IDs)**
- Что: случайная строка x-hwid, генерируемая локально при первом запуске (не hardware fingerprint).
- Зачем: app functionality — лимит устройств на аккаунте.
- Передаём: НЕТ (используется только нашим сервером выдачи).
- Обязательно.

**Активность в приложении / Диагностика**
- НЕ собирается.

**Местоположение, контакты, фото/видео, аудио, файлы, календарь, сообщения, история просмотров, поиск**
- НЕ собирается.

## Совместное использование с третьими сторонами
- НЕТ. (Вызов «Проверка утечек»/«Тест скорости» по кнопке идёт на api.ipify.org и speed.cloudflare.com — только по действию пользователя.)

## Шифрование при передаче
- ДА. Весь трафик зашифрован (TLS/REALITY). Подписка загружается по HTTPS.

## Удаление данных
- Пользователь может запросить удаление аккаунта и данных через поддержку (@bitapssupport, support@bitapsvpn.com / форма на сайте) — обрабатываем вручную. Выгрузка своих данных — кнопкой в кабинете (export-data).

# Спецификация графических ассетов для сторов

## Иконка приложения (уже есть в репо: flutter_launcher_icons)
- Google Play: PNG 512×512 (без альфа-теней, фон непрозрачный).
- App Store: PNG 1024×1024 (без альфа-канала!).

## Скриншоты
Нужны 3–8 штук, живые экраны приложения (не мокапы с текстом — ревью любит реальные UI):
1. Главная: большая кнопка подключения + статус.
2. Список серверов (реальный флот: Финляндия/Нидерланды/…).
3. Подключённое состояние + выходной IP/скорость.
4. Кабинет (подписка, устройства, ключ).

Размеры:
- Google Play телефон: минимум 1080×1920 (9:16) или 1080×2160; планшет опционально 1920×1200.
- App Store iPhone 6.9": 1290×2796 (обязателен) + iPhone 6.5": 1242×2688.
- App Store iPad 12.9": 2048×2732 (если собираем iPad-сборку; иначе пропустить).

Как снять: реальное устройство владельца (Android — scrcpy/скринкаст; iPhone — штатный скриншот).
Текст интерфейса — RU для RU-витрины, EN — для международной.

## Feature graphic (только Google Play)
- 1024×500 PNG/JPEG, тёмный фон в стиле сайта (#0d1014, акцент #ff7a1a), логотип ₿ + «bitaps VPN» + «открытый интернет».

## Видео-превью (опционально)
- До 30 сек, экранная запись: открыть → нажать → подключено. App Store preview (M4V/MOV H.264) и/или YouTube-ссылка для Play.

## Что НЕ использовать
- Скриншоты с чужими брендами/логотипами (YouTube и т.п. в узнаваемом виде) — App Store за это режектит.
- Цены на скриншотах (регионально меняются).
